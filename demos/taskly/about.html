Taskly Kanban

A calm, focused kanban board for managing tasks with drag-and-drop, filtering, and local persistence. Built entirely with vanilla HTML, CSS, and JavaScript.

Features

Drag and Drop

Move tasks between columns with intuitive drag-and-drop. Visual feedback shows drop zones.

Inline Editing

Click any task to edit its title, description, labels, and due date directly on the card.

Label Filters

Filter tasks by labels like design, feature, bug, or urgent. Combine with search for precise results.

JSON Export

Export your entire board to JSON for backup or migration. Restore from exported files.

Keyboard Navigation

Press N for new task, arrow keys to navigate, Enter to edit. Full keyboard accessibility.

Local Persistence

All data saved to localStorage automatically. Your board persists across sessions and tabs.

Technical Details
