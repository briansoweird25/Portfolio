About

Find Your Scent

A fragrance finder that understands natural language. Describe a mood, note, or budget and Aura ranks sixteen scents entirely in your browser — no API calls, no account required.

Features

Natural Language Search

Type phrases like "soft citrus for mornings" or "warm woody winter scents" and Aura interprets your intent using keyword matching and scoring.

Save to Shelf

Heart any scent to add it to your personal wardrobe. Build a collection of favorites over time.

Compare Scents

Select two scents from your shelf for side-by-side comparison of notes, price, and season.

Note Profiles

Each scent has top, heart, and base notes. Aura highlights which notes match your search for transparency.

On-Device Processing

All matching and ranking happens locally in your browser. No data sent to any server.

Responsive Design

Full-screen card layout on mobile, grid on tablet, comfortable columns on desktop. Touch-friendly interactions throughout.

Technical Details

Vanilla JavaScript
Text Matching
CSS Grid & Flex
LocalStorage
No External APIs
Zero Dependencies

Demo Scents: The sixteen fragrances are fictional but based on real note structures. Prices and descriptions are for demonstration only.
