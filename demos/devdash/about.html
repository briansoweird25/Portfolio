Northstar Analytics

A responsive analytics console demonstrating data visualization, filtering, and export capabilities. Built with vanilla HTML, CSS, and JavaScript.

Features

Interactive Revenue Charts

SVG-based line charts with hover tooltips, date range selection (7, 14, 30 days), and period comparisons.

Channel Mix Visualization

Animated donut chart showing revenue distribution across acquisition channels with legend and values.

Sortable Order Table

Paginated table with client-side sorting by date, order ID, customer, status, and amount. Filter by status.

CSV Export

Export filtered orders to CSV with proper escaping and timestamped filenames.

Theme Switcher

Light and dark modes with system preference detection and localStorage persistence.

Technical Details

Vanilla JavaScript
SVG Charts
CSS Custom Properties
LocalStorage
Responsive Layout
No Frameworks

Demo Data: All orders, customers, and revenue figures are randomly generated for demonstration purposes. No real data is collected or stored.
